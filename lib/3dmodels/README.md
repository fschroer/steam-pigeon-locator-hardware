# 3D models

Every footprint on the board points here through `${KIPRJMOD}/lib/3dmodels/...`,
so the 3D viewer and `kicad-cli pcb export step` work on any machine and in CI
without KiCad's stock 3D library installed.

- `kicad/`: unmodified copies of models from the KiCad 3D library
  (kicad-packages3D 10.0.1, CC-BY-SA 4.0 with the KiCad libraries exception).
- Top level: simplified models generated by `tools/gen_3dmodels.py` (CadQuery)
  for parts with no stock model. They use datasheet outline dimensions and the
  footprint pad positions; they are good for fit and enclosure checks, not
  for photorealism. Swap in a manufacturer STEP with the same file name to
  upgrade one.

`tools/set_3dmodels.py` rewrites the model references in the board and in
`lib/Custom.pretty` from its footprint-to-model table.

B03 additions (nRF54L15 / SX1262 sheet) come from kicad-packages3D master. Three
footprints have no stock model, so they borrow one with the same body outline:
the nRF54L15 QFN-48 6x6 uses `UQFN-48-1EP_6x6mm_P0.4mm_EP4.45x4.45mm.step`
(thinner body), and the 2012 32.768 kHz crystal and the 2016 TCXO use
`Crystal_SMD_2016-4Pin_2.0x1.6mm.step`.
